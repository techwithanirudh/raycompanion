RayCompanion 0.2.1 is the first release built and published by GitHub Actions.

- The app is unchanged from 0.2.0.
- The disk image and update archive now come with sigstore signature bundles, so you can check they were built by this repository's release workflow.

Requires macOS 26 and Apple silicon. This release is self-signed and is not notarized, so the first launch needs right-click, then Open.
