RayCompanion's first public release.

- Ask AI from Raycast with Tab, or open the full chat window.
- Use Apple Intelligence, installed AI apps, API providers and MCP tools.
- Dictate into other apps with a local speech model.
- Keep conversations, attachments and model choices between sessions.
- Set up permissions with PermissionFlow and receive signed Sparkle updates.

Requires macOS 26 and Apple silicon. This release is self-signed and is not notarized.
