RayCompanion 0.2.0 adds tools to chat.

- Chat can use a calculator, search and read files in folders you allow, and read the text selected in the app you were using.
- Import the AI tools from your installed Raycast extensions and run them in chat.
- Choose how tools ask for approval: every time, only for writes, or never. An extension that asks to confirm an action always asks.
- Codex and Claude can use the same tools, and switching between chats no longer restarts Codex.
- Pressing Stop cancels a running tool, and approval prompts wait their turn instead of being declined.
- Tab in Raycast no longer gets swallowed after the handoff stops.
- A smaller app: unused launcher features are gone.

Requires macOS 26 and Apple silicon. This release is self-signed and is not notarized, so the first launch needs right-click, then Open.
