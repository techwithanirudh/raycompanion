# Loop settings reference

Source: https://github.com/MrKai77/Loop/tree/995b1bdabde591526527819921f0f4656c1e2570

QuickChat’s SettingsView layout and SettingsTab icon treatment are adapted from Kai Azim’s Loop, licensed under GPL-3.0. The source license is included in LICENSE. The native app is distributed under GPL-3.0; third-party packages retain their own licenses.

The shell uses Loop’s 230-point LuminareSidebar, grouped LuminareSidebarSection tabs, 390-point LuminarePane, icon/title header, titlebar inset, and 620-point window height. The preview inspector and its toggle are removed. Pages contain QuickChat’s settings rather than Loop’s window-management features. Loop’s private SkyLight blur call is not included.

Luminare is pinned to 99c14e36cd536c8252ea147c36e270675fe9c187. Its own sidebar, forms, sections, toggles, and composed controls supply the styling.
